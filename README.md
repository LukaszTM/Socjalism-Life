# Socjalism-Life

Prototyp gry 3D (Godot 4, GDScript) o codziennym życiu w państwie socjalistycznym.
Główna mechanika: gospodarka niedoboru. Pieniądze są, towaru nie ma, walutą są znajomości i przysługi.

- Plan etapów: `PLAN.md`
- Pomysły na później: `POMYSLY.md`
- Licencje assetów: `LICENCJE.md`

Wymagany silnik: Godot 4.3 (Forward Plus).
